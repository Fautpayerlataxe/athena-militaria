# ---- Espaces privés : contenu personnel, aucun intérêt pour la recherche ----
# Les deux formes sont listées : les URLs du site sont désormais sans extension
# (/account), mais les anciennes URLs en .html restent atteignables et
# redirigent en 301. Bloquer les deux évite de gaspiller du crawl.
Disallow: /account
Disallow: /account.html
Disallow: /admin
Disallow: /admin.html
Disallow: /messages
Disallow: /messages.html

# ---- Brouillons non déployés ----
Disallow: /mockups

Disallow: /mockups-mix.html

# ---- Pages de résultats de recherche interne ----
# Nombre d'URLs illimité, contenu sans valeur propre pour un moteur.
Disallow: /*?q=
Disallow: /*&q=

# Les paramètres ?payment= et ?connect= ne sont volontairement PAS bloqués :
# les pages concernées portent une balise canonical qui pointe vers l'URL
# propre, ce qui consolide les signaux. Un blocage empêcherait au contraire
# les moteurs de lire cette canonical.

# ---- Ressources nécessaires au rendu ----
# Sans elles, les moteurs voient une page cassée et jugent mal la version mobile.
Allow: /*.css$
Allow: /*.js$
Allow: /*.png$
Allow: /*.jpg$
Allow: /*.webp$
Allow: /*.svg$
Allow: /pictures/

# ---- Robots des assistants et des moteurs de réponse ----
# Ces robots étaient déjà autorisés par la règle « User-agent: * » ci-dessus ;
# la mention explicite dit que c'est un choix et non un oubli.
#
# Le site vit de sa découvrabilité : les guides sont écrits pour répondre à la
# question d'un héritier ou d'un collectionneur, et être cité dans une réponse
# d'assistant amène exactement ce lectorat. La Search Console enregistrait déjà
# des impressions dans les fonctionnalités d'IA de Google avant cette mention.
#
# Les interdictions sont répétées ici, et ce n'est pas une redondance : un
# groupe nommé REMPLACE le groupe « * » pour le robot concerné, il n'y ajoute
# rien. Sans ces lignes, autoriser explicitement ces robots leur aurait ouvert
# les espaces privés et les pages de recherche interne que le groupe générique
# leur fermait jusqu'ici.
#
# Pour refuser l'un d'eux, lui donner son propre groupe avec « Disallow: / ».
